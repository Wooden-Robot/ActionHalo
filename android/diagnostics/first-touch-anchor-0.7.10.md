# Android 0.7.10：圆环仅首次触摸定位

2026-10-11；versionCode 20。

## 改动

- 每次显示的新圆环仅在第一次有效触屏按下时将中心移到按下点。后续触摸直接围绕固定中心选择操作，中心点击或回到中心松手可关闭。
- 定位标记属于当前圆环实例，分页、取消、多指中断、选文更新和外部操作失败后的重试均不重置。三个显示入口每次重新显示都会新建圆环，因此重新唤出后仍可首次定位。
- 分页按下保留分页行为，不消耗首次定位；键盘、鼠标和无障碍按钮保留原生操作路径。首次短点原图标的兼容逻辑保留，后续图标点击和长按直接使用固定中心判断。
- 普通/GTA、首页体验、选文/分享与无障碍浮层共用实现，没有新增设置或存储变更。保留 0.7.9 的图标与序号间距。

## 验证

- 离线 `assembleDebug`、`testDebugUnitTest`、`assembleDebugAndroidTest`、`lintDebug` 成功。52 项 JVM 测试通过；Lint 0 错误、5 条原有提示。
- Android 15 / API 35 ARM64，1080×2400 / 420 dpi 专用模拟器：`GtaRadialMenuTest` 19 项、`HaloIntegrationTest` 6 项，共 25 项全部通过。
- 普通/GTA 真实触摸覆盖首次定位、后续远处触摸保持中心、手势取消与多指中断不恢复定位、操作重试不恢复定位、后续图标短点和长按执行、固定中心点击关闭，以及新圆环重新允许首次定位。实际分页触摸验证分页不消耗定位机会，翻页后也不重置。
- 既有每页 6、8、12、16 项图标与序号像素间距、较大字号、链接禁用及选中预览回归通过。APK 版本、签名和修改文件空白检查通过。
- 另 6 项真实无障碍服务测试全部通过。新增真实标准选文浮层回归：首次触摸定位后取消，再次按下不改变中心，移回固定中心松手会实际移除圆环，来源选区保持不变且同一选文不会立即重弹。普通/GTA 生产浮层的首次定位后精确复制、临时弹窗焦点兼容和选文菜单归属回归也通过。

构建与设备日志位于 `android/build/diagnostics/first-touch-anchor-0.7.10/`：`build.txt`、`test-build.txt`、`instrumentation.txt`、`service-instrumentation.txt`。

## 验证边界

尚未在 vivo / Android 16 真机复测。屏幕边缘首次定位时圆环仍可能部分超出可用区域，系统栏继续由 Android 处理。
