# Android 0.9.3：应用选择列表显示名称与图标

禁用应用、生效 App、按应用规则（新增及已有规则列表）、打开方式使用同一应用标签样式：原始应用图标、主要应用名称、小号次级包名。空名称回退为包名；已卸载的保存项保留包名和系统默认应用图标。图标不额外添加背景或染色，原图自身的品牌背景保留。

`AppChoiceLabels` 复用系统 TextView、CheckBox 和 CheckedTextView，保留原有点击目标、搜索及选择监听。图标只缓存在当前对话框中；复用非应用行时清除旧图标；固定基础内边距避免重复累加系统勾选标记宽度。旧系统的固定高度列表改为随内容增高，防止两行文字裁切。不增加权限、依赖、原生库或配置字段。

## 验证

- 构建及测试 APK 打包成功，54 项 JVM 测试通过；Lint 0 错误、7 项既有警告。
- Android 8 / API 26：15 项通过；Android 15 / API 35：16 项通过。包含禁用与生效 App 的搜索、勾选、保存、取消、恢复，以及既有打开方式路由回归；按应用动作拖拽测试要求 API 29+，仅在 API 35 执行。
- 新增两项图标标签回归：LTR/RTL 下实际 CheckedTextView 多次复用后的图标、勾选标记及间距，空名称及已卸载应用的显示回退。Android 8 首轮测试发现系统行高度固定，修复后两端全部通过。
- Android 8 模拟器从实际首页进入禁用列表，确认图标、名称、包名与勾选框不重叠，搜索及保存按钮可见。截图：`android/build/app-icons-0.9.3-disabled-api26.png`。
