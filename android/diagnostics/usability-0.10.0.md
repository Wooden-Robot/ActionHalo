# Android 0.10.0 使用体验优化

## 本次范围

基于 0.9.3 的源码与界面审查，落实用户确认的八项优化。仍提供 Android 8.0 / API 26 起的通用 APK，不增加运行时依赖或原生库。

1. **链接判断**：标准选文菜单与 Telegram 助手区分“尚未取得文字”和“已知不是链接”。未知时可主动选择打开链接，按原来的明确操作复制流程取得选文，再由执行层校验 HTTP(S)；已知非链接仍禁用。不提前读取剪贴板或扫描聊天正文。
2. **执行反馈**：原生选区、菜单助手、剪贴板浮层及剪贴板入口统一使用圆环中心状态。可等待焦点恢复、明确重试或取消；不再显示继续／取消卡片。读取成功的选文快照在重试中复用，未授权、过期、锁屏及来源消失检查保留。
3. **应用与规则**：首页集中入口可搜索应用、仅查看已设置应用、管理禁用名单；应用详情展示当前设置下的触发方式、可用动作和隐藏原因。沿用既有 AppRulesStore 和动作范围，不新增规则优先级。
4. **转动稳定**：拖动跨扇区使用最多 4° 的小角度滞回；直接点按仍直接命中。GTA 缝隙、中心死区及外圈 32dp 取消区保留。
5. **边缘与小窗口**：首次空白触摸定位将轮盘与分页保持在安全范围；此后不重新跟手。小于 240dp 的空间临时使用每页 2／4 项紧凑布局，不写入用户设置，开始操作后不切布局。选文小浮窗展开时使用固定的屏幕坐标，避免窗口切换改变手势目标。
6. **图标区分**：Google、翻译、百度和豆瓣使用不同的透明矢量图标；保留中心名称预览、固定动作顺序和长按拖拽排序。
7. **设置简化**：首页展示暂停、应用规则及禁用数量；动作行显示生效范围和打开方式。应用勾选可仅看已选，搜索复用行视图。演示可折叠，执行一次后自动收起；批量停用／恢复默认收进“更多操作”。
8. **配置保护**：动作编辑、禁用列表、动作范围、应用规则和子动作排序草稿在 Activity 重建后恢复。导入展示具体变化，写入并校验本地原子备份后才覆盖配置；可恢复导入前的一份配置。待确认导入只用私有暂存文件，Bundle 保存随机 token，取消和过期时清理。
