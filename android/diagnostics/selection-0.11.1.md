# Android 0.11.1 初选静默与直接圆环

## 行为

- 撤回 0.11.0 原生初选的 48dp 轻入口，并取消 Telegram／通用菜单兼容默认出现的「打开圆环」按钮。
- 跟随全局和自动模式：初次长按选中保持静默，同一控件的选区范围改变后直接显示圆环。重复范围不重新触发；重新长按、取消后再选择及切换控件重新作为初选。
- 只有用户主动选择的应用「按钮模式」继续提供按钮。系统选文菜单中的 ActionHalo、分享及手动剪贴板入口保留。
- 初选只保留范围标记，不创建自动按钮或待显示的原生浮层。调整后的圆环仍先使用有限、不抢焦点的窗口；开始操作后再展开触摸区域和 GTA 背景，原选文手柄仍可调整。
- 保留当前应用快捷暂停、复制后保留圆环、动作搜索／编辑／排序、配置及已有焦点兼容逻辑。同步更新中英文触发说明、Telegram 授权说明与诊断建议。

自动模式仍需要来源提供选区变化信息。没有该信息的应用不会通过猜测或提前读取剪贴板触发；可主动使用系统选文菜单、分享、剪贴板入口，或为该应用选择按钮模式。此次没有加入新的延迟倒计时。

## 验证

- 修改前的原生和标准菜单两项真实选文断言均捕获到多余按钮，日志 `build/selection-0.11.1-red-api35.txt`。
- 最终构建、59 项 JVM 单元测试通过；Lint 0 错误、7 项既有警告。日志 `build/selection-0.11.1-final-build.log`。
- Android 8 / API 26：选文诊断套件报告 18 项、0 失败，其中旧 WebView 未提供原生范围和未安装 Via 各跳过一项。最终 APK 另外完成 6 项针对性检查，全部通过，包括初选、重复长按、直接调整触发、显式按钮模式、禁用应用以及第一触摸执行。日志 `build/selection-0.11.1-api26.txt`、`build/selection-0.11.1-final-api26.txt`。
- Android 15 / API 35：最终 32 项真实窗口回归全部通过，覆盖原生与菜单初选无按钮、有／无范围事件、真实手柄调整、按钮模式、精确复制、等待焦点、来源关闭、选文快照、首次定位、取消及外侧关闭。日志 `build/selection-0.11.1-verified-api35.txt`。
- 直接自动圆环在第一次触摸时才展开窗口，系统无障碍节点坐标可能短暂保留展开前的位置。定位测试改为先等待节点坐标与实际视图一致，再检查取消及后续触摸；圆环定位实现未变。临时测试探针已清理。
