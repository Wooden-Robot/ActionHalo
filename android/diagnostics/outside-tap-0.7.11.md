# Android 0.7.11：点击圆环外空白处退出

2026-10-11；versionCode 21。

## 改动

- 保留每次圆环显示后的首次触摸定位。定位后，触屏按下点距固定中心超过外半径加 32 dp 时进入关闭候选；手指没有明显移动，松手关闭且不执行对应方向的操作。静止长按后松手也关闭。
- 32 dp 范围内保留选择容错。远处关闭候选期间不显示操作预览，也不提前关闭；按下分页仍由分页处理。
- 移动超过系统 touch slop 后永久取消关闭候选，继续按固定中心方向选择。MOVE 和 UP 的历史样本也检查，滑出后返回起点不会误判为关闭；从圆环内起步拖到远处仍可选择。
- 取消、多指中断、翻页、操作失败恢复与移除视图共用既有清理路径，不重置首次定位标记。鼠标、触控笔、键盘和无障碍按钮保留原行为。
- 三个显示入口共用 `RadialMenuView`；没有新增设置、依赖或存储变更。

## 验证

- 离线 `assembleDebug`、`testDebugUnitTest`、`assembleDebugAndroidTest`、`lintDebug` 成功。52 项 JVM 测试通过；Lint 0 错误、5 条原有提示。
- Android 15 / API 35 ARM64，1080×2400 / 420 dpi 专用模拟器：`GtaRadialMenuTest` 22 项、`HaloIntegrationTest` 6 项，共 28 项全部通过。
- 新增普通/GTA 回归覆盖外缘再往外 31、32 dp 仍可选择，33 dp 点击和静止长按松手关闭；远处按下不显示操作预览；MOVE、MOVE 历史或 UP 历史越过容差后返回起点仍按方向选择；系统取消及多指中断不关闭、不执行。临界值和历史坐标通过实际父触摸面分发，远处点击和拖动另有真实系统触摸注入。
- 既有首次定位、固定中心、分页、禁用链接、每页 6、8、12、16 项图标和序号像素间距回归通过。
- 另 6 项真实无障碍服务测试全部通过。标准选文菜单浮层首次定位并取消后，在距固定中心 240 dp 的空白处按下仍保持中心，松手实际关闭；原选区及种子剪贴板保持不变，800 ms 内没有同一选文重弹。普通/GTA 生产浮层精确复制、临时焦点遮挡和菜单归属回归通过。
- APK 版本、签名检查通过；安装包与设备测试使用的生产构建一致。

构建与设备日志位于 `android/build/diagnostics/outside-tap-0.7.11/`：`build.txt`、`test-build.txt`、`instrumentation.txt`、`service-instrumentation.txt`。

## 验证边界

尚未在 vivo / Android 16 真机复测。首次触摸仍用于定位，后续远处点击才按关闭处理；边缘首次定位仍可能让圆环部分超出屏幕，系统栏由 Android 处理。
