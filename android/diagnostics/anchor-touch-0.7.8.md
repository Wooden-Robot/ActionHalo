# Android 0.7.8：按下点同步圆环中心

2026-10-11；versionCode 18。

## 改动

- 屏幕可用区域非分页位置起手时，将整个 `RadialMenuView` 的 translation 调整到按下点，实际圆环、中心提示、图标和无障碍节点一起移动。此次按下从新中心开始，没有方向预览，也不提前执行。
- 圆环中心在这一段手势中保持固定，后续滑动按新中心计算方向，松手执行；回到按下点松手取消。下一次按下重新定位，不累积旧位移。
- 所有已绑定的全屏入口共用处理：首页体验、选文/分享、手动剪贴板、普通选区无障碍浮层，以及 Telegram/通用选文菜单圆环。利用 Android 的 View 坐标变换与既有全屏事件转发，保留完整取消事件和多指处理。
- 保留原可见圆环操作的短点：无超过系统 touch slop 的移动，且短于系统长按阈值时执行原操作；移动超出阈值后不可恢复短点候选。MOVE/UP 的历史样本也参与判断。长按原图标会使用新中心，原地松手取消。
- 分页起手保留原按钮行为，不重定位；TalkBack、键盘和鼠标的原生点击行为保留。禁用链接、单次执行与手势中断的校验继续使用共用路径。

## 使用边界

圆环中心精确跟随按下点，大小保持不变。靠近屏幕边缘时部分圆环会超出可用区域，向屏幕内滑动仍可选择；屏幕外的方向无法通过手指触达。系统状态栏、导航栏与系统手势继续由 Android 处理。

无障碍浮层保持非焦点窗口，中心用于取消；系统返回键可能仍交给来源应用。设备验证使用模拟器与独立测试宿主，尚未在 vivo / Android 16 / 真实 Telegram、X 上复测。
