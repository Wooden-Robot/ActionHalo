# Android 0.8.6：选区可调整的自动圆环

验证日期：2026-10-12。版本 `0.8.6` / `29`，最低 Android 8.0（API 26），目标 API 36，继续提供单一通用 APK。

## 行为

自动圆环出现时，原页面保持清晰，不启用 GTA 模糊、调暗或薄雾。窗口只占圆环所在的方形区域，周围触摸传给原应用，因此可以继续拖动选区手柄。触摸圆环后才展开完整操作层，启用原有 GTA 背景；第一次直接点图标仍在同一次松手执行，无需额外确认。

没有新增选区空闲倒计时或相关设置；原生选区事件保留原有的 250 ms 合并机制。无法统一观察所有应用的手柄松手事件，本次通过保留原应用触摸区域解决阻挡问题。手动选文菜单、分享、剪贴板和首页诊断入口仍直接进入完整圆环。

自动窗口尽量放在选区或已核对的复制菜单上下方，并保留系统栏和边缘空间。原生控件提供字符坐标时，只请求选区首尾各一个字符的位置，并为手柄留出边距；不提供时按控件范围避让。Telegram/通用菜单路径只使用已有复制控件位置，不为定位而扫描消息、读取剪贴板或截图。

自动圆环尚未开始操作时，触摸其窗口外会回到原应用并收起圆环；改变选区后可再次出现。进入完整操作层后保留现有的图标点选、首次空白定位、中心取消、分页和外缘 32 dp 距离限制。完整操作层内的触摸由圆环处理；需要继续改选时先关闭圆环。

## 实现与故障修复

`SelectionHaloWindow` 共用于原生选区和 Telegram/通用菜单浮层。初始窗口使用 `NOT_FOCUSABLE`、`NOT_TOUCH_MODAL` 和 `WATCH_OUTSIDE_TOUCH`，首次圆环触摸时扩展窗口并复用 `HaloAppearance.bindBackdrop`。扩展期间用屏幕坐标转换同一次手势，避免窗口局部坐标变化导致第一次松手落在错误位置；第一帧保持图标中心位置。

复制菜单兼容测试发现：拖动手柄时，系统可能移除旧工具栏，再为同一页面创建新窗口。圆环此前仍等待旧窗口，选中操作会停在等待状态。现在在原先核对过的页面窗口内重新核对唯一复制菜单，允许菜单窗口更新，并继续尚未执行的用户操作。保留应用、父窗口、标准菜单身份、可见性、密码/敏感控件、授权和新鲜剪贴板检查；原页面消失时仍取消，不跨页面借用菜单。

没有新增权限、依赖、原生库、截图逻辑或用户文字日志；已有动作、顺序、授权和外观偏好保持。未采用先前未交付的长时间空闲等待草稿。

## 验证

JDK 17 / SDK 36 下，`assembleDebug`、`assembleDebugAndroidTest`、`testDebugUnitTest` 和 `lintDebug` 全部通过。**54 项 JVM 测试通过，无失败、错误或跳过**。

Android 15 / API 35 ARM64：**72 项用例中 71 项通过、1 项条件跳过，无失败**，用时 244.725 秒。包括 `GtaRadialMenuTest` 25 项、`HaloIntegrationTest` 7 项、`SettingsPagesTest` 4 项、`FocusedClipboardOverlayTest` 24 项及 `SelectionTriggerDiagnosticTest` 12 项。Via 实际浏览器用例因未提供测试网址跳过；固定 WebView 的长按选文检查通过。运行日志为 `selection-adjustment-0.8.6-api35-final-regression.txt`。

新增真实窗口检查在不同 UID 的固定文本应用里长按选文，等圆环已经显示后，再注入连续触摸拖动原生手柄：选区由 9 字符扩展到 18 字符；随后第一次点 Copy，核对剪贴板中的内容确实为调整后的完整片段。分别覆盖原生选区和关闭选区事件的标准菜单路径。修复菜单替换后，该检查连续执行三次均通过。

另一项检查记录首次扩展窗口的首个绘制帧，确认已按下图标的中心不偏移、背景按需启用，并在同一次松手执行 Copy。现有首次定位、取消、外侧关闭、距离限制、权限撤回、原生选区优先和执行过渡检查继续纳入回归。

Android 8.0 / API 26 ARM64：**6 项针对性检查通过**，分两批运行，分别用时 19.237 秒和 2.331 秒。包括原生可编辑/只读长按、清晰选区窗口及首帧点选、两种圆环模式的点选和按住操作、外侧缓冲往返、旧系统 GTA 回退和 0% 遮罩。

构建、修复前后的复现日志、固定文本截图和源文件差异位于 `android/build/diagnostics/`，文件前缀为 `selection-adjustment-0.8.6-`。失败日志保留；中间诊断探针已从测试代码移除。

## 验证边界

未在 vivo 或其他品牌真机、真实 Telegram/X、其他 CPU 架构运行。应用不提供选区或可核对的复制菜单时，仍需使用手动选文菜单、分享或剪贴板入口。窗口避让依赖应用公开的字符/控件/菜单位置；缺少精确坐标或屏幕空间不足时，不能保证避开所有自定义手柄。Android 8–11 以及系统关闭模糊时仍使用 GTA 遮罩回退。
