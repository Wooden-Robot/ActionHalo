# Android 0.11.0 常用操作优化

## 六项实现

1. **初次选文轻入口**：原生初始选区使用 48dp 独立、不抢焦点、不展开 GTA 的按钮。点按后重新校验来源与当前选区再打开圆环；调整后的自动触发、密码与受保护区域过滤保留。
2. **当前应用快捷停用**：已确认来源的圆环有「⋮」。有来源窗口 ID 时可暂停本次使用，来源窗口被其他应用替换、锁屏或服务结束后恢复；临时焦点遮挡保持暂停。另有该 App 暂停 10 分钟和永久禁用。现有独立动作顺序保留，手动入口不被自动规则拦截，规则页可提前恢复临时暂停。无法确认来源的手动分享不猜测 App；没有来源窗口 ID 时不提供本次使用暂停。
3. **复制后继续**：可选开关默认关闭，位于触发设置。手动圆环、无障碍原生选文及菜单复制桥共用。复制成功后留在原圆环，继续使用本次选文；30 秒到期、关闭、离开或锁屏清理。焦点恢复不会自动重复动作，也不会读取新的剪贴板替换快照。
4. **可操作的诊断**：优先检查当前授权、连接和暂停状态，再解释最近一次固定类别结果。区分禁用／暂停、初始选区待点按、未暴露选文、受保护区域、等待焦点、复制时效失效及动作失败，提供授权、后台、规则、动作或触发设置入口。诊断不读取消息、剪贴板或保存 App 使用记录。
5. **动作管理**：名称／网址搜索保持原顺序，搜索时禁用拖拽以免误写全局位置，查询跨 Activity 重建恢复。可编辑的网站动作可复制为新动作，保存时继承启用状态、范围及打开方式；取消不创建。编辑器可用示例预览编码后的链接，只有明确点击打开测试网址才跳转；输入和预览不发请求。
6. **紧凑首页**：移除大段宣传文案，状态、自动开关、动作／外观、应用规则、暂停和手动剪贴板入口优先。诊断／权限／关于／备份集中在下方，演示区可折叠。设置页打开时不自动召出搜索键盘。

- `assembleDebug`、`assembleDebugAndroidTest`、59 项 JVM 单元测试通过，Lint 0 错误、7 项既有警告；日志 `build/daily-0.11.0-build.log`。
- API 26：首轮 52 项圆环、GTA、配置及设置回归通过；第二轮 29 项通过；真实选文、锁屏、键盘与配置等 15 项通过；最终安装包 13 项针对性检查通过。日志 `build/daily-0.11.0-{first,second,final,check}-api26.txt`。
- API 35：动作搜索、复制动作、测试链接和配置重建等针对性 16 项通过；选文、焦点、剪贴板、GTA 和规则完整回归 76 项通过；最终安装包的固定诊断示例、保留快照、失败重试和应用快捷停用等 10 项通过。日志 `build/daily-0.11.0-{second,final,check}-api35.txt`。最新安装包中文环境的动作搜索、编辑、复制、链接测试和拖拽排序 9 项全部通过，日志 `build/daily-0.11.0-actions-final-api35.txt`。批次有重叠，不合计为独立用例数。
- 检查了紧凑首页、友好诊断及当前应用快捷设置的实际截图，位于 `build/daily-0.11.0-{home-api35,diagnostics-api35,source-options}.png`。
- 中文回归的测试预期统一使用应用选择的语言，避免把合法的本地化名称变化误判为动作变化。初次轻入口改变了旧测试仅凭“一个浮窗”判断完整圆环的条件，已改为等待真正圆环且保持恰好一个浮窗。修复搜索框默认焦点影响拖拽滚动、菜单兼容单独开启时固定诊断示例被清理，以及复制成功后旧错误提示回显。
- 本次选文的 30 秒上限不会因重复复制延长；已取得的快照在重试与继续操作时复用，关闭后清空。只有用户明确打开测试网址才产生外部跳转。
