# Android 0.8.7：初次长按保持静默

验证日期：2026-10-12。版本 `0.8.7` / `30`，最低 Android 8.0（API 26），目标 API 36，继续提供单一通用 APK。

## 行为

长按后第一次出现非空选区时，只记录控件、窗口与范围，不自动显示圆环。同一控件的选区范围改变后，才进入已有的自动圆环流程；相同范围的重复事件不会触发，也不会取消已经等待显示的更新。取消选区、切换控件或来源窗口后重新选字，重新作为初选处理。应用提供长按事件时，再次长按另一处文字也会重置初选状态。

没有增加空闲倒计时或相关设置，原生选区路径保留原有 250 ms 事件合并。自动圆环仍使用 0.8.6 的清晰、可继续操作原页面的有界窗口；触摸圆环后才展开完整操作层并启用 GTA 背景。手动选文菜单中的 ActionHalo、分享、剪贴板和首页检查入口不受初选规则限制。

Telegram / 通用菜单兼容也遵守初选静默。首次识别到经过核对的复制菜单时，只提供小号「打开圆环」按钮；可继续调整文字，选好后主动点它。菜单来源同时提供选区变化时，调整后可以自动显示圆环。只显示按钮或圆环不会复制或读取剪贴板；选择具体动作后才沿用已核对的复制控件及有焦点浮层执行操作。

这类入口无法统一获得每个应用的选区变化，小按钮保留为兼容入口，没有新增入口开关。Telegram 12.10.6 正文的接口限制沿用 [固定版本检查记录](telegram-compatibility.md)，不将菜单出现、窗口变化或系统翻译提示当成选区已经调整。

## 实现范围

`SelectionAccessibilityService` 在首次有效选区保存元数据，后续同源范围变化才建立待显示请求。新增长按事件订阅以重置可观察的新一轮选字；使用刷新后的控件范围，保留旧事件与新选区的竞争处理，以及密码、敏感控件、锁屏和来源窗口检查。

`TelegramCopyAssistant` 记录范围元数据，区分小按钮和真正圆环。只有真正圆环占用选文操作；小按钮不会抢占原生选区路径。主动打开时重新核对同一宿主的复制菜单，取消选区时清除调整状态。原生选区优先、复制工具栏替换、临时遮挡、待执行动作、旧剪贴板拒绝及权限撤回逻辑保留。

更新中英文说明、诊断状态、测试宿主及回归用例。没有新增权限、依赖、原生库、背景剪贴板监听、用户文字日志或跨应用截图功能。本文提到的截图与触摸注入仅用于隔离模拟器内的固定测试应用。

## 验证

JDK 17 / SDK 36 下，`assembleDebug`、`assembleDebugAndroidTest`、`testDebugUnitTest` 和 `lintDebug` 通过。**54 项 JVM 测试通过，无失败、错误或跳过**。Lint 为 0 错误、7 警告。

Android 15 / API 35 ARM64 最终完整回归：**76 项用例中 75 项通过、1 项条件跳过，无失败**，用时 280.403 秒。范围为 `GtaRadialMenuTest` 25 项、`HaloIntegrationTest` 7 项、`SettingsPagesTest` 4 项、`FocusedClipboardOverlayTest` 26 项及 `SelectionTriggerDiagnosticTest` 14 项。Via 实际浏览器检查因未提供测试网址跳过；固定 WebView 的真实手柄拖动检查通过。最终日志为 `initial-selection-0.8.7-api35-final-verified.txt`，`TestRunner` 记录核对了全部 76 项及唯一的 Via 条件跳过。

新增检查覆盖首次非空选区、重复事件、实际范围变化、取消后重新选字、再次长按另一单词、小按钮真实点按与打开前不复制。不同 UID 的固定文本应用中注入连续触摸，拖动真正的选区手柄，分别覆盖原生选区、提供变化事件的标准菜单、屏蔽变化事件的标准菜单。前两种在调整后自动显示，最后一种仍需主动打开；随后核对复制的准确片段。

WebView 检查先实际长按并确认没有圆环，再根据系统公布的手柄窗口位置拖动真实右手柄。该 WebView 只在选区事件里提供范围，不支持普通文本框的 `ACTION_SET_SELECTION`，也不返回字符位置附加数据；测试没有用这些接口假定成功。通用菜单用例关闭原生自动路径，以单独验证小按钮兼容。

Android 8.0 / API 26 ARM64：**8 项针对性检查通过**，原生初选、重复事件、调整、重新长按、可编辑/只读选文、旧 WebView 小按钮、清晰选区窗口与首帧点选共 6 项，用时 22.245 秒；圆环两种模式的点选与外侧拖动限制共 2 项，用时 7.863 秒。

测试校准包括：等待旧系统页面进场完成后再设置选区；窗口标题缺失时，按本应用小按钮根节点识别辅助入口；对 WebView 使用实际范围事件及手柄窗口。修复前的初选失败、测试输入接口不支持和校准过程日志均保留，不作为通过记录。

构建日志、最终回归、固定文字截图与相对本次修改前的源文件差异位于 `android/build/diagnostics/`，前缀 `initial-selection-0.8.7-`。

## 验证边界
