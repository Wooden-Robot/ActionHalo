# Android 0.9.0 使用体验优化

范围：用户选择前两轮提出的全部十项优化。保留 Android 8 / API 26 最低版本与单一通用 APK，使用原生 View 和现有圆环，不引入依赖或原生库。

## 功能与入口

| 项目 | 实现 |
| --- | --- |
| 1. 按应用触发 | 触发与权限中的应用规则：跟随全局、自动、按钮、停用。原生读取需已有选文同意；菜单兼容继续使用原有独立同意。 |
| 2. 键盘与单手位置 | 初始放置避让可见 IME 矩形，支持自动 / 左下 / 右下；第一次开始操作后保留指下坐标。 |
| 3. 故障反馈 | 首页区分关闭、暂停、授权关闭和服务断开；提供对应恢复及手动入口。动作失败在圆环中央显示错误，保留文字，可再次明确选择动作。 |
| 4. 配置备份 | 系统文件选择器导出 / 导入 JSON，确认替换；包含动作、顺序、外观、应用规则及打开方式。1 MiB / 200 自定义动作上限，全部内容验证后才写入。 |
| 5. 实时预览 | 外观页固定预览，可点选、拖动、分页、关闭 / 重新试用；不执行实际动作，改变设置立即刷新。 |
| 6. 指定打开方式 | 网站动作可指定已安装处理程序；指定程序失败使用相同网址回退。Telegram 明确选择某个客户端后，失败不改投其他客户端、不伪造网页搜索。 |
| 7. 临时暂停 | 设置页与快捷设置磁贴支持 10 分钟 / 1 小时 / 恢复；不修改系统无障碍授权，手动入口可继续使用。 |
| 8. 每应用动作组合 | 从完整动作目录选择并保持独立顺序，支持长按拖拽 / 边缘滚动 / 箭头；取消拖动或对话框不改变已保存配置。 |
| 9. 编辑选文 | 默认关闭的可选动作，主动编辑后回到圆环，保留已知来源的动作组合。仅内存持有编辑内容，旋转恢复，不回写来源或剪贴板。 |
| 10. 撤销 | 删除自定义动作、全部停用、恢复默认动作、重置外观后提供 15 秒撤销；后续更改或离开当前页面使旧撤销失效。 |

## 关键实现边界

- 配置备份不含选文、剪贴板、消息、诊断、运行状态、暂停时间或权限同意。不会从备份自动授予访问权限。无效文件全部预校验失败，不改变当前配置；恢复跨多个 SharedPreferences，不提供进程被强制终止情况下的事务原子性。
- 文件类型、结构、原始值类型、动作引用、ID、HTTP(S) 模板、尺寸范围、UTF-8 和大小都校验。删除自定义动作后的陈旧配置引用仅在导出中剔除，本地保留引用以便撤销恢复。
- 原生 / 菜单辅助读取继续核对真实来源、当前选区 / 本次复制时间及前台焦点。失败后只保留首次成功读取的快照，不重复读取；临时抢焦点恢复不自动重试失败动作，再次点击后才执行。重复失败保留同一个圆环及手指锚点。
- 原生选区第一次仍保持静默；同一来源调整范围后才自动触发。按钮模式始终由用户点按钮打开。应用不暴露选区或复制菜单时仍需手动入口。
- 来源不明的分享 / 手动剪贴板使用全局动作；正常自动选文、菜单辅助复制及其后续编辑保留可靠来源包名。
- 普通 Activity 无法获得不报告遮挡范围的悬浮键盘位置；无障碍浮层使用实际 IME 窗口。已开始手势后不自动重新放置圆环。
- 预览展示圆环及背景色层，完整实时跨窗口模糊在实际圆环中查看。

## 验证

构建：`assembleDebug`、`assembleDebugAndroidTest`、`testDebugUnitTest`、`lintDebug`。54 项 JVM 测试通过（9 个套件，无失败、错误或跳过）；Lint 0 错误、7 项既有警告。

所有设备均为本机专用模拟器，只使用固定测试文字。最终结果如下。

| 设备 | 范围 | 结果 |
| --- | --- | --- |
| API 26 / Android 8 | 原有圆环与手动入口 | 32 项通过 |
| API 26 / Android 8 | 新配置 / 编辑 / 备份 / 预览，以及动作管理、搜索和剪贴板 | 58 项通过；部分 API 29+ 用例按条件不运行 |
| API 26 / Android 8 | 初选静默、按钮模式、应用停用 / 暂停及标准菜单兼容 | 4 项通过 |
| API 35 / Android 15 | 选文来源、真实焦点中断与恢复、动作失败后的明确重试、原有圆环手势 | 75 项通过；未安装 Via 的真实浏览器诊断按条件不运行 |
| API 35 / Android 15 | 新设置、撤销、编辑、备份、预览、动作管理及搜索 | 67 个用例通过：完整批次中 66 项通过，独立动作拖拽用例修正坐标后单独复测通过 |
| API 26 / Android 8 | 系统快捷磁贴 | 实际添加并打开时长选择；暂停 10 分钟后再次点击恢复，核对持久化状态 |
| API 26 / Android 8 | 系统文件选择器与实时预览 | Downloads 导出 JSON → 选择同一文件 → 确认替换 → 显示恢复成功；实际查看固定预览布局 |

测试修正没有放宽生产规则：API 26 的按钮用例原先在页面还不可见时设置选区，增加真实可见性等待后通过；独立动作排序用例原先把对话框根坐标用于屏幕触摸注入，改用 `getLocalVisibleRect` 与 `getLocationOnScreen`，并正确结束取消后的注入触摸流。复测覆盖预览、取消恢复、连续拖放、取消编辑及两层确认后保存。临时诊断日志已全部移除。

日志保存在本机 `android/build/ux-0.9.0-*.txt`；主要结果为 `api26-final-ui`、`api26-gestures`、`api26-source-fixed`、`api35-regression`、`api35-final-ui`、`api35-app-rules-drag-fixed`。固定测试配置与文件选择器完成状态分别保存在 `ux-0.9.0-api26-saf-export.json`、`ux-0.9.0-api26-backup-complete.xml`。
