# Android 0.7.5：长按拖拽与透明图标

2026-10-11；versionCode 15。

## 改动

- 首页操作行、开关文字区域及右侧「⋮」均可长按开始原生拖拽。拖影跟随手指，列表实时预览新位置；松手在列表内放下时保存最终索引，取消或在列表外放下恢复原顺序。
- 拖到首页可见区域的上下边缘时自动滚动，便于跨多行排序；放下、离开拖拽区域、取消和销毁界面均停止滚动回调。
- 预览仅重排现有行 View，不写配置；有效放下通过共用 `ActionStore.moveTo` 保存一次。关闭项参与排序，原有启用状态、编辑字段与各圆环入口读取方式保留。「⋮ → 上移/下移」继续可用，并共用同一保存逻辑。
- 删除 `ic_launcher.xml` 的全画布深色矩形。保留八扇区圆环及高亮轮廓，外围、中心与缝隙透明；Manifest 与首页图标共用此资源。10 个动作矢量原本已无独立底色，无需修改圆环分区背景。
