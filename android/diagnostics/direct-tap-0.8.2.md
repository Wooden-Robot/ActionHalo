# Android 0.8.2：首次点选保持圆环原位

验证日期：2026-10-12。版本 `0.8.2` / `25`，最低 Android 8.0（API 26），目标 API 36，继续只提供通用 APK。

## 问题与实现

旧实现无论首次按在哪里，都立即把圆环中心移到按下点，再用短点补判执行原图标。因此直接点选会看到圆环跳位，长按还受短点超时限制。

在三个入口共用的 `RadialMenuView` 中调整首次触摸规则：

- 首次非分页触摸落在圆环内，保持原位置。点图标立即预览，松手执行；按住滑动仍按原中心选择。中心、不可用动作和 GTA 缝隙也不触发移动。
- 首次触摸落在圆环外空白处，仍立即把中心同步到手指下，随后围绕该点选择。
- 此次触摸之后位置固定，取消、分页或操作失败重试均不重新定位。首次触摸被取消也不会重新获得定位机会，避免无法退出。
- 保留中心关闭、外缘以外 32 dp 缓冲后的静止点击关闭、远处滑动方向选择、禁用动作校验、单次执行及多指取消。分页、鼠标、键盘和原生无障碍点击沿用原路径。

删除不再需要的原图标短点补判字段、超时分支和中心距离辅助函数。手动选文/分享、原生无障碍选区、Telegram/通用复制菜单入口自动共用修复；未修改动作数据、排序或外观配置。

## 验证

使用现有 JDK 17 / SDK 36 构建，`assembleDebug`、`assembleDebugAndroidTest`、54 项 JVM 测试及 Lint 全部通过。

Android 15 / API 35 ARM64 一次性模拟器设备测试共 **33 项通过**，分两次执行：

- `GtaRadialMenuTest`：23 项。新增首次点击/长按图标保持原位、松手执行一次，以及首次点禁用图标后取消仍锁定位置并可在外部关闭的回归检查；同时回归旋转、返回中心、远处关闭、滑动历史、多指、取消、分页、两种模式、图标布局与无障碍按钮。
- `HaloIntegrationTest`：7 项。回归手动选文、分享、复制、动作管理和网页动作。
- `FocusedClipboardOverlayTest`：3 项。标准选文菜单完整复制、标准菜单外部首次定位复制、原生选区外部首次定位复制。使用真实服务、窗口和触摸以及固定合成选文。

首轮 32 项用时 101.114 秒，补跑完整复制检查 1 项用时 8.542 秒。日志位于 `android/build/diagnostics/direct-tap-0.8.2-build.txt`、`direct-tap-0.8.2-api35-tests.txt` 和 `direct-tap-0.8.2-copy-test.txt`。
