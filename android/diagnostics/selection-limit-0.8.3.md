# Android 0.8.3：限制圆环功能选择距离

验证日期：2026-10-12。版本 `0.8.3` / `26`，最低 Android 8.0（API 26），目标 API 36，继续只提供通用 APK。

## 实现

旧版按方向选择时没有外侧距离上限，拖到离圆环很远的位置后松手仍可能执行功能。本版在共用 `RadialGeometry.hitTest` 中限制为圆环外半径加 **32 dp**，按屏幕密度换算；边界上仍可选择，超过边界返回 `Outside`。

- 手指超出范围后取消高亮和动作预览；按住期间不执行、不关闭，滑回有效范围恢复选择。
- 松手重新判断当时的位置，超出范围关闭圆环且不执行，不能沿用之前高亮的动作。即使没有最后一次 MOVE 事件也同样处理。
- 删除旧版根据触摸容差和历史采样区分远处点击/拖动的状态，避免拖动绕过距离上限。远处起手后移回范围内也可选择，无需先移动超过系统触摸容差。
- 普通/GTA、手动选文/分享、原生无障碍选区、Telegram/通用复制菜单入口共用规则。首次空白定位、图标点选不跳位、中心关闭、分页、禁用动作、单次执行及多指取消继续回归。
- 更新首页中英手势说明与 README。未修改动作、排序、外观或权限配置，未增加依赖或设置选项。

- `GtaRadialMenuTest`：24 项，覆盖滑出取消高亮、滑回恢复、外部起手后短距离移回、松手位置重新核对、历史采样不绕过上限，并回归两种模式的点选、旋转、取消、关闭、首次定位、分页与无障碍按钮。
- `HaloIntegrationTest`：7 项，覆盖手动选文、分享、复制、首页和动作管理。
- `FocusedClipboardOverlayTest`：3 项，覆盖真实服务和窗口中的标准菜单准确复制、标准菜单外部定位复制、原生选区外部定位复制；使用固定合成选文。

日志：`android/build/diagnostics/selection-limit-0.8.3-build.txt`、`selection-limit-0.8.3-api35-tests.txt`。版本、签名及文件校验结果见同目录 `selection-limit-0.8.3-artifact.json`。
